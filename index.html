Pengaturan
  1. Buka Google Sheets baru di browser
  2. Klik menu Extensions > Apps Script
  3. Hapus semua kode default, lalu paste kode di bawah
  4. Klik Deploy > New Deployment
  5. Pilih tipe Web App
  6. Set Execute as: Me
  7. Set Who has access: Anyone
  8. Klik Deploy, izinkan akses
  9. Salin URL yang muncul, paste di kolom atas
